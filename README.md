# subscription_plan💳 Subscription Plan Webpage

This project is a responsive subscription/pricing plan webpage built using HTML and CSS (Flexbox). It is designed to display different subscription options in a structured and user-friendly way, making it ideal for practicing layout design and showcasing Flexbox skills.

🔹 Project Overview

The webpage contains multiple subscription cards (Basic, Standard, Premium, etc.) arranged side by side using Flexbox. Each card highlights:

Plan name

Price

Key features

Call-to-action button

The design is kept simple, modern, and responsive, ensuring it looks good on desktop as well as mobile devices.

✨ Features

Responsive design using Flexbox

Clean and professional UI for pricing/subscription plans

Well-structured and beginner-friendly code

Hover effects for better user interaction

Easy customization for different pricing models

🛠️ Technologies Used

HTML5 for structure

CSS3 (Flexbox) for styling and layout
